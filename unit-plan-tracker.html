Share & backup guide

How this tracker stores data

This page has no server or database — everything you add is saved privately in this browser's local storage, on this device only. Nobody else who opens the same link will see your entries automatically.

Using it inside Teams

  1. Host this file somewhere reachable by a URL — e.g. upload unit-plan-tracker.html to a SharePoint document library, or publish this repository with GitHub Pages.
  2. In your Teams channel, click + at the top of the tabs bar → choose Website → paste the URL → Save.
  3. The tracker now opens as a tab for anyone in the channel. Each person's edits still save to their own browser, so agree on one owner (usually the HOD) who keeps the master copy.

Using it inside SharePoint

  1. Upload unit-plan-tracker.html to a document library, or embed it on a SharePoint page using the Embed web part with the file's shareable/download link.
  2. Pin the page to your department site's navigation for quick access.

Keeping everyone in sync

  • Use Export CSV when you want to review the data in Excel, or archive it alongside your old spreadsheet.
  • Use Export JSON to make a full backup, then Import that file on another device (or after clearing your browser) to restore everything exactly as it was.
  • A simple workflow: the HOD keeps the "live" copy in their browser, exports a JSON backup weekly, and saves it to the team's SharePoint folder.
